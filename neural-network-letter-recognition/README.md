# Neural Network for Letter Recognition

## Overview
This project implements an energy-based binary neuron network
on a 2D lattice to recognize letter patterns under noisy conditions.

## Model
- Binary neurons with local interactions
- Energy minimization framework inspired by magnetization models
- Stochastic noise introduced to test robustness

## Results
The model successfully recognizes structured letter patterns
and degrades predictably under increasing randomization.

## How to Run
I used Spyder to run this code with no install necessary.
### Functions
In the main() function, there are a number of functions for plotting, along with acc(), animate(), and test(). test() was used for debugging purposes and was often edited and scrapped for different uses. acc() measured the accuracy as randomization increased. animate() was a fun little animation I made of one singular guess of the model, mostly for presentaiton purposes.
